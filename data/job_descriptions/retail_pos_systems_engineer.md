# Retail Point-of-Sale (POS) Systems Architect
**Company**: OmniStore Tech
**Department**: Retail Technology
**Location**: Multiple Locations / Remote

## Role Overview
Build resilient, offline-capable store checkout terminals and omnichannel inventory synchronization systems.

## Key Responsibilities
- Architect offline-first desktop POS software with local SQLite caching and eventual sync.
- Integrate with peripheral hardware: barcode scanners, receipt printers, and EMV payment chip terminals.
- Ensure zero duplicate charges during intermittent store internet outages.
- Deploy automated remote software updates across 3,000 retail store terminals.

## Required Qualifications
- 5+ years building Point of Sale (POS) or enterprise retail transaction systems.
- C# / .NET, Electron, or Java desktop experience.
- Deep understanding of offline-first synchronization patterns and conflict resolution.
- Experience with payment terminal protocols.
