# Real-Time Streaming Data Engineer (Flink / Kafka)
**Company**: StreamWave Analytics
**Department**: Streaming Infrastructure
**Location**: Multiple Locations / Remote

## Role Overview
Build sub-second event streaming platforms processing 500,000 events/second with Apache Flink and Kafka.

## Key Responsibilities
- Develop stateful streaming applications using Apache Flink and Kafka Streams.
- Implement exactly-once processing semantics across distributed consumer workers.
- Manage Kafka broker clusters, partition rebalancing, and Schema Registry.
- Monitor streaming consumer lag and author automated backpressure handlers.

## Required Qualifications
- 4+ years building production streaming pipelines.
- Apache Flink, Apache Kafka, Scala or Java.
- Deep understanding of event-time processing and watermarking.
- Experience with distributed storage (ClickHouse, Pinot, RocksDB).
