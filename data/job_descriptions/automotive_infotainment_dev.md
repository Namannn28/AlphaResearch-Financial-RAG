# Automotive Infotainment Software Engineer (Android Automotive)
**Company**: DriveOS Mobility
**Department**: Connected Car
**Location**: Multiple Locations / Remote

## Role Overview
Build responsive in-vehicle infotainment (IVI) and digital cockpit software using Android Automotive OS (AAOS).

## Key Responsibilities
- Develop native in-vehicle applications in Kotlin compliant with driver distraction safety guidelines.
- Interface with vehicle hardware buses via Vehicle Hardware Abstraction Layer (VHAL).
- Optimize touch responsiveness and cold-boot times on automotive-grade Qualcomm Snapdragon chips.
- Execute automated UI tests simulating varied vehicle speeds and driving conditions.

## Required Qualifications
- 4+ years in Android software development with experience in Android Automotive OS (AAOS) or AOSP.
- Strong Kotlin and modern Android architecture proficiency.
- Understanding of vehicle networks (CAN, Ethernet) and safety constraints.
- Familiarity with automotive testing frameworks.
