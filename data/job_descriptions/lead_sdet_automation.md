# Lead Software Development Engineer in Test (SDET)
**Company**: QualityScale Labs
**Department**: Quality Engineering
**Location**: Multiple Locations / Remote

## Role Overview
Design automated end-to-end testing frameworks, parallel execution runners, and performance benchmarks.

## Key Responsibilities
- Build scalable automated testing frameworks from scratch using TypeScript and Playwright.
- Integrate automated API integration test suites into GitHub Actions CI pipelines.
- Establish synthetic monitoring health checks running against production endpoints.
- Mentor manual QA testers in test automation and modern test design.

## Required Qualifications
- 5+ years as an SDET or test automation engineer.
- Mastery of Playwright, Cypress, or Selenium with TypeScript/Python.
- Strong background in REST and GraphQL API testing.
- Experience with CI/CD integration and test reporting.
