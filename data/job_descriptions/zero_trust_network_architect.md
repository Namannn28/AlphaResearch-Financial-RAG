# Zero-Trust Architecture Lead
**Company**: TrustZero Systems
**Department**: Enterprise Security
**Location**: Multiple Locations / Remote

## Role Overview
Lead company-wide migration from perimeter VPNs to modern software-defined Zero-Trust perimeter networks.

## Key Responsibilities
- Deploy secure application access proxies using Cloudflare Access or Zscaler Private Access.
- Enforce mutual TLS (mTLS) with device certificate posture verification across corporate endpoints.
- Collaborate with IT to decommission legacy corporate VPN concentrators.
- Conduct user training and ensure frictionless access for global remote employees.

## Required Qualifications
- 5+ years in network security and identity architecture.
- Deep knowledge of zero-trust network principles (NIST SP 800-207).
- Experience with Zscaler, Cloudflare Zero Trust, or Palo Alto Prisma.
- Strong cross-departmental project management skills.
