# High-Scale PostgreSQL Tuning & Reliability Lead
**Company**: PostgresMasters
**Department**: Data Reliability
**Location**: Multiple Locations / Remote

## Role Overview
Provide expert database performance optimization, connection pool scaling, and query tuning.

## Key Responsibilities
- Diagnose and eliminate transaction ID wraparound risks and autovacuum starvation.
- Tune multi-gigabyte queries using EXPLAIN ANALYZE and custom partial/expression indexes.
- Architect zero-downtime database sharding and partitioning strategies using Citus.
- Manage disaster recovery and physical streaming replication topologies.

## Required Qualifications
- 6+ years dedicated PostgreSQL database administration and query performance optimization.
- Deep understanding of MVCC, WAL internals, and lock contention modes.
- Experience with PgBouncer connection pooling and Patroni high-availability.
- Linux system internals and disk I/O profiling expertise.
