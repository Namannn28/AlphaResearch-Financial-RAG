# AdTech Real-Time Bidding (RTB) Engineer
**Company**: BiddingSpeed Networks
**Department**: Ad Platform
**Location**: Multiple Locations / Remote

## Role Overview
Build real-time bidding auction engines evaluating bid requests within a strict 20-millisecond hard deadline.

## Key Responsibilities
- Design ultra-fast auction decision microservices in C++ or Rust responding in under 15ms.
- Implement high-throughput in-memory user profile lookup using Aerospike or Dragonfly.
- Optimize network packet serialization and connection reuse across global ad exchanges.
- Analyze click fraud patterns and anomalous impression spam.

## Required Qualifications
- 4+ years in AdTech or real-time trading systems.
- Mastery of C++, Rust, or ultra-optimized Go.
- Experience with OpenRTB 2.5 / 3.0 specifications.
- Obsessive focus on microsecond latency profiling.
