# Multi-Cloud Kubernetes Platform Architect
**Company**: KubeSphere Global
**Department**: Platform Engineering
**Location**: Multiple Locations / Remote

## Role Overview
Standardize declarative container platforms across AWS EKS, GCP GKE, and bare-metal environments.

## Key Responsibilities
- Build standardized enterprise Kubernetes platforms across AWS, GCP, and on-premise clusters.
- Implement service mesh infrastructure using Istio for mTLS, traffic splitting, and telemetry.
- Standardize cluster admission control using Kyverno and Open Policy Agent (OPA).
- Train internal engineering teams on cloud-native best practices.

## Required Qualifications
- 6+ years dedicated Kubernetes platform engineering.
- Deep knowledge of Kubernetes internals, API extensions, and operators.
- Experience with Istio, ArgoCD, and Helm.
- Multi-cloud operational experience.
