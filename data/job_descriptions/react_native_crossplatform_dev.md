# Senior React Native Engineer
**Company**: OmniMobile Labs
**Department**: Mobile Engineering
**Location**: Multiple Locations / Remote

## Role Overview
Build scalable cross-platform mobile apps using React Native, TypeScript, and native bridge modules.

## Key Responsibilities
- Develop fluid mobile interfaces using React Native and React Navigation.
- Write custom Swift / Kotlin bridge modules for proprietary device hardware interactions.
- Profile memory leaks and optimize JavaScript thread frame rates using Flipper.
- Implement code-push over-the-air updates and telemetry tracking with Bugsnag.

## Required Qualifications
- 4+ years software engineering with 2+ years in React Native.
- Solid mastery of TypeScript, React hooks, and mobile lifecycle components.
- Experience with native iOS (Xcode) and Android (Android Studio) build tooling.
- Understanding of offline-first persistence with MMKV or SQLite.
