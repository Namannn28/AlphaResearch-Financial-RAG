# Lakehouse Performance & FinOps Engineer
**Company**: CloudSave Data
**Department**: Cloud FinOps
**Location**: Multiple Locations / Remote

## Role Overview
Audit and optimize cloud data warehouse storage and compute expenses across Snowflake and Databricks.

## Key Responsibilities
- Analyze Snowflake query profiling and warehouse utilization to eliminate wasted compute credits.
- Optimize Delta Lake and Iceberg table file compaction (Z-Ordering, bin-packing) to accelerate queries.
- Implement automated warehouse auto-suspend and scaling policies.
- Deliver monthly executive cost attribution and savings reports.

## Required Qualifications
- 4+ years in data engineering with deep focus on query optimization and cloud costs.
- Expertise in Snowflake, Databricks, or BigQuery internal cost models.
- Advanced SQL performance tuning and index optimization.
- Demonstrated history of saving $100k+ in cloud compute spend.
