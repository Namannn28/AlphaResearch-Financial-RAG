# Avionics Software Verification Engineer (DO-178C)
**Company**: AeroDynamics Corp
**Department**: Aerospace Systems
**Location**: Multiple Locations / Remote

## Role Overview
Develop and verify safety-critical flight control software adhering to FAA DO-178C Level A standards.

## Key Responsibilities
- Author deterministic C code for flight management and autopilot sensor processing.
- Execute structural coverage analysis (MC/DC - Modified Condition/Decision Coverage) on embedded code.
- Develop hardware-in-the-loop (HIL) automated test benches simulating flight dynamics.
- Participate in formal FAA certification audits and safety reviews.

## Required Qualifications
- 4+ years in safety-critical software development (avionics, automotive, or medical devices).
- Hands-on experience with DO-178C or ISO 26262 compliance.
- Proficiency in embedded C, static analysis tools (Polyspace), and requirement traceability.
- Uncompromising dedication to safety and verification.
