# Enterprise Data Governance & Quality Engineer
**Company**: SecureData Corp
**Department**: Data Governance
**Location**: Multiple Locations / Remote

## Role Overview
Lead enterprise data cataloging, lineage tracking, data privacy, and metadata management across 200+ databases.

## Key Responsibilities
- Implement enterprise data catalog platforms (Alation, Collibra, or Apache Atlas).
- Map end-to-end data lineage from source transactional databases to reporting dashboards.
- Enforce automated data quality SLA monitoring and incident alerting.
- Audit compliance with GDPR, CCPA, and industry data retention standards.

## Required Qualifications
- 4+ years in data governance, data quality, or data management.
- Experience with enterprise data catalog tools (Collibra, Alation, Unity Catalog).
- Strong SQL and data profiling capabilities.
- Familiarity with regulatory data compliance laws.
