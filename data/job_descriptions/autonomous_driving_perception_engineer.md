# Autonomous Vehicle Perception Engineer
**Company**: DriveCore Labs
**Department**: Autonomous Mobility
**Location**: Multiple Locations / Remote

## Role Overview
Develop 3D LiDAR point cloud and multi-camera sensor fusion pipelines for autonomous vehicles.

## Key Responsibilities
- Train 3D object detection models on point clouds using PointNet and BEVFormer.
- Implement Kalman filters for multi-sensor tracking and state estimation.
- Optimize perception algorithms to meet deterministic safety-critical latency budgets (<30ms).
- Validate algorithms against simulation suites and real-world drive data.

## Required Qualifications
- 3+ years perception engineering for robotics or autonomous driving.
- C++17 and Python proficiency.
- Experience with LiDAR, radar, and camera sensor fusion.
- Knowledge of ROS / ROS2 and automotive safety standards (ISO 26262).
