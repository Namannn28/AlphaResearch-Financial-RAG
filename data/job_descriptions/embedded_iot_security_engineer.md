# Embedded Device & IoT Security Specialist
**Company**: SecureSilicon Labs
**Department**: Hardware Security
**Location**: Multiple Locations / Remote

## Role Overview
Perform hardware teardowns, side-channel analysis, and firmware reverse engineering on connected devices.

## Key Responsibilities
- Extract and reverse-engineer firmware images from flash memory chips using SPI/JTAG dumpers.
- Audit embedded C/C++ code against memory corruption vulnerabilities (buffer overflows, format strings).
- Evaluate cryptographic hardware accelerators, secure elements, and secure boot implementations.
- Author hardware security assessment reports with actionable mitigation advice.

## Required Qualifications
- 3+ years in hardware hacking, embedded security, or firmware reverse engineering.
- Experience with Ghidra, IDA Pro, and hardware debugging tools (Bus Pirate, logic analyzers).
- Knowledge of ARM architecture and hardware attacks (glitching, side-channel).
- Strong ethical hacking mindset.
