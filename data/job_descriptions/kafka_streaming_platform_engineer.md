# Kafka Platform & Event Streaming Specialist
**Company**: EventFlow Cloud
**Department**: Streaming Core
**Location**: Multiple Locations / Remote

## Role Overview
Operate, scale, and secure enterprise Apache Kafka clusters handling 50 billion events daily.

## Key Responsibilities
- Manage multi-broker Apache Kafka and Schema Registry clusters on Kubernetes using Strimzi.
- Tune broker heap sizing, page cache utilization, and replication throttle limits.
- Implement automated partition rebalancing and topic quota governance.
- Troubleshoot consumer rebalances, poison pill messages, and SSL/SASL authentication.

## Required Qualifications
- 4+ years dedicated Apache Kafka operations and development.
- Deep understanding of Kafka storage internals (segment files, log compaction, index files).
- Experience with Kafka monitoring (JMX metrics, Prometheus, Cruise Control).
- Proficiency in Python or Java for event streaming.
