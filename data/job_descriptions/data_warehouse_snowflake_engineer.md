# Senior Snowflake Data Warehouse Engineer
**Company**: SnowScale Analytics
**Department**: Data Architecture
**Location**: Multiple Locations / Remote

## Role Overview
Design high-performance dimensional data warehouses, data sharing, and Snowpark transformations.

## Key Responsibilities
- Architect scalable data marts and dimensional models on Snowflake utilizing Kimball methodologies.
- Develop automated data ingestion pipelines using Snowpipe and external stages on AWS S3.
- Implement programmatic data transformations using Snowpark Python and stored procedures.
- Optimize virtual warehouse credit consumption through query profile analysis and clustering keys.

## Required Qualifications
- 4+ years in data warehousing with 2+ years dedicated to Snowflake.
- SnowPro Core Certification preferred.
- Mastery of advanced SQL and Python.
- Deep experience with data modeling and analytics architectures.
