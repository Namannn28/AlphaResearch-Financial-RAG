# Software Release Engineering Manager
**Company**: DeployGuard Inc
**Department**: Release Operations
**Location**: Multiple Locations / Remote

## Role Overview
Manage production release schedules, zero-downtime deployment gates, and hotfix rollback procedures.

## Key Responsibilities
- Coordinate weekly production releases across 12 distributed engineering squads.
- Enforce deployment verification gates, staging smoke tests, and rollback runbooks.
- Chair the Change Advisory Board (CAB) to assess release risks and cross-service dependencies.
- Manage emergency hotfix deployments and conduct post-incident release retrospectives.

## Required Qualifications
- 5+ years in release management, DevOps, or software engineering leadership.
- Deep understanding of continuous deployment strategies (canary, blue-green, feature flags).
- Strong risk assessment and crisis leadership capabilities.
- Experience with feature flagging platforms (LaunchDarkly).
