# CI/CD Pipeline & Build Release Engineer
**Company**: FastDeploy Systems
**Department**: Developer Infrastructure
**Location**: Multiple Locations / Remote

## Role Overview
Build ultra-fast, secure automated build, test, and deployment pipelines using GitHub Actions.

## Key Responsibilities
- Design reusable GitHub Actions workflows used by 500+ software engineers.
- Implement container image caching, dependency caching, and parallelized test runners.
- Integrate automated security gates (SAST, DAST, container scanning) into merge queues.
- Maintain 99.9% CI runner cluster availability on self-hosted autoscaling runners.

## Required Qualifications
- 4+ years building automated CI/CD pipelines.
- Mastery of GitHub Actions, GitLab CI, or Jenkins.
- Docker, Linux shell scripting, and Python.
- Familiarity with container security scanning tools (Trivy, Snyk).
