# LLM Prompt & Fine-Tuning Engineer
**Company**: PromptFlow Tech
**Department**: Applied AI
**Location**: Multiple Locations / Remote

## Role Overview
Specialize in parameter-efficient fine-tuning (PEFT/LoRA) and deterministic prompt orchestration.

## Key Responsibilities
- Fine-tune open-source models (Llama 3, Mistral) on domain-specific corpora using QLoRA and Unsloth.
- Author complex prompt chains with structured JSON outputs and function calling.
- Evaluate prompt robustness against edge cases and system prompt leakage.
- Optimize prompt token efficiency to reduce cloud API expenditures.

## Required Qualifications
- 2+ years working with LLMs, prompt engineering, and fine-tuning.
- Hands-on experience with HuggingFace, PEFT, TRL, and Unsloth.
- Familiarity with structured output libraries (Instructor, Outlines).
- Attention to detail and linguistic nuance.
