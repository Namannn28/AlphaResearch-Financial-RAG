# Senior SOC Incident Response Analyst
**Company**: ThreatShield Defense
**Department**: Security Operations
**Location**: Multiple Locations / Remote

## Role Overview
Lead real-time threat investigation, malware analysis, and security incident containment.

## Key Responsibilities
- Investigate high-severity security alerts across EDR systems (CrowdStrike Falcon, SentinelOne).
- Perform forensic disk, memory, and network packet analysis during suspected breaches.
- Develop automated security orchestration playbooks (SOAR) to isolate compromised endpoints.
- Author formal post-incident root-cause investigation reports.

## Required Qualifications
- 3+ years in security operations or incident response.
- GIAC Certified Incident Handler (GCIH) or equivalent.
- Experience with SIEM (Splunk, Microsoft Sentinel) and EDR platforms.
- Strong understanding of Windows and Linux forensic artifacts.
