# Staff Data Platform Engineer
**Company**: Horizon Intelligence
**Location**: Seattle, WA / Remote
**Department**: Data & Analytical Systems

## Role Overview
Horizon Intelligence is seeking a Staff Data Platform Engineer to anchor our next-generation streaming lakehouse and feature store architecture. You will be responsible for scaling our petabyte-scale data pipelines, establishing data contracts, and delivering low-latency analytical data products.

## Key Responsibilities
- Architect, build, and optimize streaming and batch data pipelines using Apache Spark, Apache Flink, and Delta Lake / Apache Iceberg.
- Own data platform reliability, cost optimization, and automated quality testing (Great Expectations, dbt).
- Modernize internal feature stores to serve real-time and offline ML training workloads.
- Establish enterprise data governance, RBAC access policies, and schema drift prevention.
- Mentor junior and mid-level data engineers across technical design reviews and architectural RFCs.

## Required Qualifications
- 6+ years of specialized experience in data engineering, distributed streaming systems, and data warehousing.
- Masterful command of Python, SQL, Scala, and the Apache Spark ecosystem.
- Hands-on expertise building production lakehouses with Delta Lake, Apache Iceberg, or Snowflake.
- Strong track record managing streaming architectures with Apache Kafka or Apache Flink.
- Experience with infrastructure as code (Terraform) and workflow orchestration (Apache Airflow).

## Preferred Qualifications
- Active open-source contributions to Apache Arrow, Iceberg, Spark, or related ecosystems.
- Proven experience achieving substantial cloud cost reductions on AWS/Databricks infrastructure.
