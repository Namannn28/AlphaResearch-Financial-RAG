# Cyber Threat Intelligence & OSINT Developer
**Company**: DarkTrace Defense
**Department**: Threat Intelligence
**Location**: Multiple Locations / Remote

## Role Overview
Build automated web scrapers, dark web monitoring daemons, and threat indicator enrichment pipelines.

## Key Responsibilities
- Develop automated threat intelligence collectors ingesting data from dark web forums and paste sites.
- Extract and enrich Indicators of Compromise (IOCs) using MISP, STIX, and TAXII standards.
- Correlate IOCs against corporate asset logs to identify potential active reconnaissance.
- Author daily executive threat briefings summarizing emerging ransomware campaigns.

## Required Qualifications
- 3+ years in cyber threat intelligence or security data engineering.
- Strong Python scripting and automated web scraping skills.
- Experience with threat sharing standards (STIX 2.1, TAXII, MISP).
- Understanding of adversary tactics and ransomware ecosystems.
