# Travel & Hospitality Global Distribution Engineer
**Company**: GlobalStay Networks
**Department**: Travel Platform
**Location**: Multiple Locations / Remote

## Role Overview
Build high-concurrency hotel and flight booking reservation engines connecting to Global Distribution Systems (GDS).

## Key Responsibilities
- Integrate booking APIs with global distribution systems (Amadeus, Sabre) via OTA XML and REST.
- Implement low-latency room availability caching using Redis with sub-50ms search times.
- Ensure transactional consistency during concurrent room booking attempts.
- Manage currency conversion, tax calculation, and multi-language localization.

## Required Qualifications
- 4+ years in travel technology or high-volume booking platforms.
- Proficiency in Java, Python, or Go.
- Deep experience with distributed caching (Redis) and relational database transactions.
- Familiarity with GDS or OTA hospitality API standards.
