# IoT Cloud & Telemetry Platform Engineer
**Company**: IoTLab Global
**Department**: Connected Devices
**Location**: Multiple Locations / Remote

## Role Overview
Build cloud platforms ingesting telemetry from 5 million connected smart home sensors over MQTT.

## Key Responsibilities
- Deploy scalable MQTT broker clusters (EMQX, VerneMQ) processing 100,000 messages per second.
- Ingest time-series telemetry into TimescaleDB or ClickHouse for real-time sensor analytics.
- Implement device authentication using X.509 certificates and secure device shadow synchronization.
- Build automated firmware update (OTA) campaign management tools.

## Required Qualifications
- 4+ years in IoT cloud architecture and device telemetry.
- Deep knowledge of MQTT, CoAP, and HTTP/2 protocols.
- Experience with time-series databases (TimescaleDB, InfluxDB, ClickHouse).
- Python, Go, or Java backend proficiency.
