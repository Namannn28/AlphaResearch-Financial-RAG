# Senior Database Administrator (PostgreSQL DBA)
**Company**: DataCore Systems
**Department**: Database Operations
**Location**: Multiple Locations / Remote

## Role Overview
Manage, scale, tune, and ensure 99.999% availability for enterprise PostgreSQL database clusters.

## Key Responsibilities
- Tune PostgreSQL configurations, shared buffers, work_mem, and autovacuum parameters.
- Manage high-availability clusters using Patroni, Raft, and streaming replication.
- Execute zero-downtime major version database upgrades on terabyte-scale databases.
- Analyze slow query logs, pg_stat_statements, and create optimal indexes.

## Required Qualifications
- 5+ years dedicated PostgreSQL administration in production environments.
- Deep expertise with replication, backups (pgBackRest), and failover tooling (Patroni).
- Linux systems performance tuning and disk I/O profiling.
- Experience with connection pooling (PgBouncer).
