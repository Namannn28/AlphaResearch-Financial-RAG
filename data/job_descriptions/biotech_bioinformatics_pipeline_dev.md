# Bioinformatics Pipeline & NGS Engineer
**Company**: GenomeTech Labs
**Department**: Genomics Core
**Location**: Multiple Locations / Remote

## Role Overview
Build automated Next-Generation Sequencing (NGS) data processing pipelines on cloud HPC clusters.

## Key Responsibilities
- Author reproducible genomic variant calling workflows using Nextflow, Snakemake, and Docker.
- Process raw FASTQ / BAM sequencing files using GATK, BWA, and Samtools.
- Orchestrate high-performance computing (HPC) batch workloads on AWS Batch and Slurm.
- Collaborate with computational biologists to analyze rare disease genetic variants.

## Required Qualifications
- 3+ years in bioinformatics pipeline development or computational genomics.
- Expertise in Nextflow or Snakemake workflow orchestrators.
- Familiarity with genomics tools (GATK, BWA, VCF tools).
- Strong Python and Bash scripting skills.
