# Automated Data Quality & Reliability Engineer
**Company**: ReliableData Labs
**Department**: Data Assurance
**Location**: Multiple Locations / Remote

## Role Overview
Build automated validation frameworks ensuring data pipelines never ship silent corruptions to production.

## Key Responsibilities
- Author automated data expectation test suites using Great Expectations and Soda Core.
- Implement automated schema migration checks that block breaking upstream column deletions.
- Build Slack and PagerDuty notification webhooks for data pipeline anomalies.
- Collaborate with data engineers to establish SLOs for data freshness and validity.

## Required Qualifications
- 3+ years in data quality, data testing, or analytics engineering.
- Strong Python and SQL scripting skills.
- Experience with Great Expectations, Soda, or Monte Carlo.
- Obsessive attention to data correctness and edge cases.
