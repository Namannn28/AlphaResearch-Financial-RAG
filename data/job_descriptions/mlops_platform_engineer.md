# Staff MLOps Platform Engineer
**Company**: ModelScale Tech
**Department**: ML Infrastructure
**Location**: Multiple Locations / Remote

## Role Overview
Build automated model registry, feature store, and continuous model training/deployment pipelines.

## Key Responsibilities
- Orchestrate automated training DAGs with Kubeflow Pipelines and Ray.
- Maintain enterprise feature store with Feast and Redis.
- Implement automated drift detection and model retraining triggers using Evidently AI.
- Standardize model packaging with MLflow and Docker.

## Required Qualifications
- 5+ years building MLOps infrastructure.
- Kubernetes, Kubeflow, MLflow, Ray.
- Experience with feature stores (Feast, Hopsworks).
- Python and Go proficiency.
