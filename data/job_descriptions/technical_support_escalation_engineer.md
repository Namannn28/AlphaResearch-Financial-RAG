# Tier-3 Technical Support Escalation Engineer
**Company**: ResolvCloud
**Department**: Customer Support
**Location**: Multiple Locations / Remote

## Role Overview
Investigate complex customer edge cases, reproduce software defects, and author hotfix patches.

## Key Responsibilities
- Analyze application stack traces, database logs, and network pcaps to triage urgent production issues.
- Reproduce customer edge cases in sandboxed staging environments.
- Collaborate with core software engineers to submit bug fix pull requests.
- Author detailed technical Knowledge Base articles and post-mortem incident documentation.

## Required Qualifications
- 3+ years in technical support escalation, QA, or software engineering.
- Ability to read and debug code in Python, JavaScript, or Java.
- Strong database querying skills (SQL) and log analysis (Splunk, Datadog).
- Exceptional customer empathy and written communication under pressure.
