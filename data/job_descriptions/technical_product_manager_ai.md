# Technical Product Manager (Developer AI Platform)
**Company**: AIPlatform Pro
**Department**: Product Management
**Location**: Multiple Locations / Remote

## Role Overview
Define the product roadmap, user stories, and developer experience for our enterprise LLM API gateway.

## Key Responsibilities
- Conduct user discovery interviews with developer customers to identify developer friction.
- Write detailed Technical Product Requirement Documents (PRDs) for model serving and RAG capabilities.
- Define product telemetry KPIs: developer activation rate, API latency satisfaction, and retention.
- Collaborate closely with engineering leads to prioritize the bi-weekly sprint backlog.

## Required Qualifications
- 4+ years as a Technical Product Manager for developer tools or cloud platforms.
- Computer Science background or ability to write API queries and understand architecture diagrams.
- Strong customer empathy and data-driven prioritization.
- Excellent communication and sprint leadership skills.
