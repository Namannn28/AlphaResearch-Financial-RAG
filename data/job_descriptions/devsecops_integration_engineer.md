# DevSecOps Integration Specialist
**Company**: PipelineShield
**Department**: Security Engineering
**Location**: Multiple Locations / Remote

## Role Overview
Embed automated security testing seamlessly into developer git commit workflows and pull requests.

## Key Responsibilities
- Build pre-commit git hooks and GitHub Actions workflows scanning for hardcoded secrets (TruffleHog).
- Integrate Open Policy Agent (OPA) / Conftest to block insecure Terraform manifests prior to apply.
- Deliver security tool feedback directly into developer PR comments to avoid developer friction.
- Track developer fix rates and security debt across repositories.

## Required Qualifications
- 3+ years in DevSecOps or platform engineering.
- Strong proficiency with GitHub Actions, Terraform, and Docker.
- Hands-on experience with secret scanning and policy-as-code tools (OPA, Checkov).
- Empathy for developer velocity.
