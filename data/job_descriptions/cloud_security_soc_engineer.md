# Cloud Security Operations (SOC) Detection Engineer
**Company**: CloudWatchdog Sec
**Department**: Cyber Detection
**Location**: Multiple Locations / Remote

## Role Overview
Author high-fidelity detection rules, threat hunt queries, and automated incident containment playbooks.

## Key Responsibilities
- Write and tune detection rules in Splunk, Sumo Logic, or Snowflake using Sigma and YARA-L.
- Conduct threat hunting exercises across AWS CloudTrail, VPC Flow Logs, and Okta system logs.
- Automate alert triage and false positive reduction using Python and webhook automations.
- Participate in on-call security incident response shifts with standard operating procedures.

## Required Qualifications
- 3+ years in SOC analysis, detection engineering, or cloud security.
- Strong familiarity with AWS CloudTrail, GuardDuty, and Kubernetes audit logs.
- Proficiency with SIEM query languages (SPL, KQL, SQL).
- Analytical mindset for separating malicious anomalies from normal developer activity.
