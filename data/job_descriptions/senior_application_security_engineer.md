# Senior AppSec & DevSecOps Engineer
**Company**: Apex Financial Technologies
**Department**: Application Security
**Location**: Multiple Locations / Remote

## Role Overview
Lead automated CI/CD vulnerability scanning, API penetration testing, and zero-trust architectures.

## Key Responsibilities
- Operationalize SAST/DAST security scanning with Semgrep and Snyk.
- Perform API penetration testing identifying OWASP Top 10 vulnerabilities.
- Implement Zero-Trust network access with Okta and mTLS.
- Attain and maintain SOC 2 Type II compliance.

## Required Qualifications
- 5+ years application security experience.
- OSCP, CISSP, or AWS Security Specialty.
- Semgrep, Snyk, Burp Suite Pro, Falco.
- Proven vulnerability remediation leadership.
