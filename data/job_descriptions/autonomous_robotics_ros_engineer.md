# Robotics Software Engineer (ROS 2 / Navigation)
**Company**: RoboFleet Dynamics
**Department**: Autonomous Robotics
**Location**: Multiple Locations / Remote

## Role Overview
Develop autonomous mobile robot (AMR) navigation, path planning, and obstacle avoidance using ROS 2 and C++.

## Key Responsibilities
- Implement SLAM (Simultaneous Localization and Mapping) and trajectory planning algorithms in ROS 2.
- Optimize costmap calculations and dynamic obstacle avoidance for warehouse environments.
- Interface with hardware sensors (LiDAR, ultrasonic, depth cameras) over CAN bus and Ethernet.
- Simulate warehouse robotic fleets using Gazebo before real-world deployment.

## Required Qualifications
- 3+ years experience with ROS / ROS 2 and modern C++.
- Strong understanding of kinematics, path planning (A*, Dijkstra, DWA), and SLAM.
- Experience with Gazebo simulation and sensor integration.
- Hands-on debugging on physical robotic hardware.
