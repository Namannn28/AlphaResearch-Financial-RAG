# E-Commerce High-Concurrency Platform Engineer
**Company**: PrimeCart Commerce
**Department**: Core Storefront
**Location**: Multiple Locations / Remote

## Role Overview
Build flash-sale checkout engines capable of handling 200,000 concurrent checkout requests during Black Friday.

## Key Responsibilities
- Design inventory reservation locking mechanisms utilizing Redis distributed locks (Redlock).
- Optimize checkout database transactions to prevent overselling while maximizing throughput.
- Implement asynchronous order processing queues with Kafka and dead-letter handling.
- Conduct rigorous peak load testing and chaos injection ahead of annual shopping holidays.

## Required Qualifications
- 5+ years in high-traffic e-commerce or transactional systems.
- Deep knowledge of database concurrency, optimistic locking, and distributed caching.
- Proficiency in Go, Java, or Node.js.
- Proven track record handling Black Friday scale traffic.
