# Senior Linux Systems Administrator (RHEL / Ubuntu)
**Company**: ServerCore Technologies
**Department**: Core Infrastructure
**Location**: Multiple Locations / Remote

## Role Overview
Maintain enterprise Linux server fleets, kernel tuning, security hardening, and storage arrays.

## Key Responsibilities
- Manage 800+ physical and virtual Linux servers running Red Hat Enterprise Linux and Ubuntu.
- Implement security hardening according to CIS Benchmarks and DISA STIG guidelines.
- Automate server configuration management using Ansible playbooks.
- Diagnose low-level kernel panics, CPU throttling, and network interface bottlenecks.

## Required Qualifications
- 5+ years enterprise Linux administration.
- Red Hat Certified Engineer (RHCE) or equivalent.
- Deep knowledge of systemd, SELinux, LVM, and networking (iptables, firewalld).
- Proficiency in Bash and Python scripting.
