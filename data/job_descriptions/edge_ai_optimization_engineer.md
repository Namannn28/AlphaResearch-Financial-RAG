# Edge AI Optimization & Compilers Engineer
**Company**: TinySilicon Corp
**Department**: Edge Intelligence
**Location**: Multiple Locations / Remote

## Role Overview
Optimize deep learning models for custom NPUs, microcontrollers, and low-power hardware.

## Key Responsibilities
- Utilize TVM and MLIR to compile deep neural networks for proprietary NPU architectures.
- Implement pruning, quantization (INT4, FP8), and knowledge distillation techniques.
- Profile memory bandwidth and compute utilization on target embedded hardware.
- Collaborate with hardware architects to specify next-generation accelerator instructions.

## Required Qualifications
- 3+ years in deep learning compiler engineering or edge optimization.
- Knowledge of TVM, MLIR, ONNX, TensorRT.
- C++ and Python mastery.
- Understanding of computer architecture and cache hierarchies.
