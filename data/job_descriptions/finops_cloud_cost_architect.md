# Cloud FinOps & Infrastructure Optimization Architect
**Company**: CloudBudget AI
**Department**: FinOps
**Location**: Multiple Locations / Remote

## Role Overview
Lead organizational cloud cost attribution, spot instance adoption, and commitment discount strategies.

## Key Responsibilities
- Implement granular cost allocation tagging and dashboards across multi-account AWS environments.
- Lead spot instance migration strategies for fault-tolerant background workloads.
- Manage AWS Savings Plans and Reserved Instance portfolio optimization.
- Collaborate with engineering leads to establish monthly team cloud budgets.

## Required Qualifications
- 4+ years in cloud infrastructure with dedicated focus on FinOps.
- FinOps Certified Practitioner (FOCP) preferred.
- Deep knowledge of AWS Cost Explorer, CUR (Cost and Usage Report), and Datadog.
- Strong analytical and cross-functional leadership skills.
