# Telecom 5G Core Network Software Engineer
**Company**: NovaTel Networks
**Department**: Telco Cloud
**Location**: Multiple Locations / Remote

## Role Overview
Develop cloud-native 5G core network functions (AMF, SMF, UPF) deployed on containerized telco clouds.

## Key Responsibilities
- Implement 3GPP compliant 5G service-based architecture (SBA) network functions in C++ or Go.
- Optimize User Plane Function (UPF) packet forwarding utilizing DPDK (Data Plane Development Kit).
- Deploy telco cloud infrastructure on Kubernetes with SR-IOV and DPDK CNI plugins.
- Participate in interoperability testing with major telecom equipment vendors.

## Required Qualifications
- 4+ years in telecommunications or network protocol engineering.
- Deep knowledge of 3GPP 5G specifications and protocol stacks (HTTP/2, PFCP, GTP-U).
- C++ or Go programming with DPDK experience.
- Understanding of network virtualization (NFV, SDN).
