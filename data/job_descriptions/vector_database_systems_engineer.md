# Vector Database Systems Engineer (Milvus / Qdrant)
**Company**: VectorScale Corp
**Department**: Vector Infrastructure
**Location**: Multiple Locations / Remote

## Role Overview
Design and scale high-throughput vector index storage and similarity search infrastructure.

## Key Responsibilities
- Deploy and manage distributed Milvus, Qdrant, or Pinecone clusters on Kubernetes.
- Tune Approximate Nearest Neighbor (ANN) index algorithms (HNSW, IVF-PQ) for recall vs latency trade-offs.
- Benchmark vector search query latency under 10,000 QPS load.
- Implement hybrid sparse-dense vector storage architectures.

## Required Qualifications
- 3+ years in vector search, IR, or high-performance distributed storage.
- Hands-on experience with Milvus, Qdrant, FAISS, or ChromaDB.
- Understanding of distance metrics (Cosine, Euclidean, Dot Product) and vector quantization.
- Kubernetes deployment expertise.
