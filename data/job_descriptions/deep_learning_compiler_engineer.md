# Deep Learning Compiler Engineer (MLIR / TVM)
**Company**: TensorSpeed Hardware
**Department**: AI Compilers
**Location**: Multiple Locations / Remote

## Role Overview
Develop optimization passes and hardware code generators for neural network operations.

## Key Responsibilities
- Author custom MLIR dialects, transformations, and pattern rewriting passes for tensor algebra.
- Optimize kernel code generation for SIMD vector units, GPUs, and custom AI accelerators.
- Benchmark and reduce memory footprint through graph-level operator fusion and memory planning.
- Collaborate with open-source compiler communities (LLVM, MLIR, Apache TVM).

## Required Qualifications
- 3+ years in compiler engineering or deep learning systems optimization.
- Strong C++17 programming and software engineering discipline.
- Knowledge of LLVM, MLIR, or TVM architectures.
- Deep understanding of hardware memory hierarchies and parallel computing.
