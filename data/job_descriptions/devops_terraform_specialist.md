# Infrastructure as Code Specialist (Terraform & Pulumi)
**Company**: InfraCode Partners
**Department**: Cloud Automation
**Location**: Multiple Locations / Remote

## Role Overview
Standardize multi-environment enterprise cloud automation using modular Terraform and Pulumi.

## Key Responsibilities
- Author modular, reusable, versioned Terraform modules adhering to HashiCorp best practices.
- Implement automated module validation and linting using tflint, trivy, and infracost.
- Manage multi-state environments and remote state locking with Terraform Cloud and AWS S3/DynamoDB.
- Conduct peer reviews for infrastructure pull requests and enforce zero-drift policies.

## Required Qualifications
- 4+ years dedicated infrastructure-as-code automation.
- HashiCorp Certified: Terraform Associate.
- Deep experience with AWS or GCP resource provisioning.
- Strong shell scripting and GitOps pipeline skills.
