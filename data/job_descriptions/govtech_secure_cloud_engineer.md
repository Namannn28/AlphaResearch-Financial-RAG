# GovTech FedRAMP Cloud Security Engineer
**Company**: CivicCloud Systems
**Department**: Public Sector Cloud
**Location**: Multiple Locations / Remote

## Role Overview
Architect FedRAMP High and DoD IL5 compliant cloud infrastructure for state and federal government agencies.

## Key Responsibilities
- Build automated cloud compliance guardrails adhering to NIST SP 800-53 security controls.
- Manage government isolated cloud regions (AWS GovCloud, Azure Government).
- Automate System Security Plan (SSP) evidence collection and vulnerability scanning.
- Collaborate with government agency security officers during Authority to Operate (ATO) assessments.

## Required Qualifications
- 4+ years in cloud security with dedicated FedRAMP or government compliance experience.
- Active or eligible for US Security Clearance preferred.
- Deep knowledge of NIST SP 800-53, FIPS 140-2, and FedRAMP requirements.
- Terraform and AWS GovCloud mastery.
