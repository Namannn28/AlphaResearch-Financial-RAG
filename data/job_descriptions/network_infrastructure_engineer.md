# Cloud & Hybrid Network Infrastructure Engineer
**Company**: NetBridge Solutions
**Department**: Network Engineering
**Location**: Multiple Locations / Remote

## Role Overview
Design high-performance hybrid network topologies connecting on-premise data centers to AWS via Direct Connect.

## Key Responsibilities
- Configure and operate AWS Direct Connect, Transit Gateways, and VPN tunnels.
- Manage BGP routing tables, VPC peering, and overlapping IP address subnetting (NAT gateways).
- Implement cloud network security using AWS Network Firewall and security group automation.
- Troubleshoot packet drops, MTU misconfigurations, and latency anomalies with Wireshark.

## Required Qualifications
- 4+ years in enterprise and cloud networking.
- Cisco CCNP or AWS Certified Advanced Networking – Specialty.
- Deep understanding of BGP, IPsec, TCP/IP, and DNS architectures.
- Experience with network automation tools.
