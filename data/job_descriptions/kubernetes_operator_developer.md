# Kubernetes Operator & Controller Developer (Go)
**Company**: OperatorCraft
**Department**: Cloud Native Core
**Location**: Multiple Locations / Remote

## Role Overview
Build custom Kubernetes Custom Resource Definitions (CRDs) and controllers using Kubebuilder and Go.

## Key Responsibilities
- Design declarative Custom Resources and reconciliation controllers using Kubebuilder and Controller-Runtime.
- Manage lifecycle operations (backup, failover, upgrades) for stateful applications on Kubernetes.
- Implement admission webhooks for CRD validation and default mutation.
- Write comprehensive integration tests using envtest and Kuttl.

## Required Qualifications
- 3+ years in Go systems programming and Kubernetes API extension.
- Deep knowledge of Kubernetes client-go, informers, workqueues, and reconcilers.
- Experience packaging and distributing operators via OperatorHub and Helm.
- Strong understanding of distributed state management.
