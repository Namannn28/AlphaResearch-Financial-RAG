# Senior Recommendation Systems Engineer
**Company**: ShopStream Media
**Department**: Discovery & Personalization
**Location**: Multiple Locations / Remote

## Role Overview
Architect multi-stage personalized recommendation engines handling 50M active shoppers.

## Key Responsibilities
- Design candidate generation (two-tower models) and re-ranking deep neural networks.
- Optimize negative sampling and cold-start candidate discovery.
- Deploy real-time inference with Triton Inference Server and Milvus vector retrieval.
- Run online A/B testing measuring click-through rate (CTR) and conversion.

## Required Qualifications
- 4+ years building large-scale recommendation or search systems.
- Deep learning for recsys (Two-Tower, DLRM, Transformer-based).
- Distributed training with Ray or PyTorch DDP.
- Solid understanding of online experimentation and A/B testing statistics.
