# High-Throughput Data Ingestion Engineer
**Company**: FastIngest Tech
**Department**: Core Ingestion
**Location**: Multiple Locations / Remote

## Role Overview
Build resilient connectors and ingestion daemons moving terabytes of operational telemetry into analytical warehouses.

## Key Responsibilities
- Design distributed ingestion workers using Go, Python, and Kafka.
- Handle schema drift and unannounced upstream payload changes gracefully without pipeline failure.
- Implement exponential backoff retry buffers and dead-letter queues (DLQ).
- Maintain 99.99% ingestion availability SLAs.

## Required Qualifications
- 3+ years in distributed data ingestion or backend pipelines.
- Proficiency in Go or Python.
- Hands-on experience with Kafka, Debezium, or AWS Kinesis.
- Experience with schema validation (JSON Schema, Avro, Protobuf).
