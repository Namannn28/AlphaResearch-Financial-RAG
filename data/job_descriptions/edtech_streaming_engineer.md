# EdTech Real-Time Streaming Engineer (WebRTC)
**Company**: EduStream Live
**Department**: Live Learning
**Location**: Multiple Locations / Remote

## Role Overview
Build ultra-low-latency interactive classroom streaming infrastructure for synchronous global online learning.

## Key Responsibilities
- Deploy selective forwarding units (SFU) utilizing Mediasoup or Pion WebRTC in Go.
- Implement adaptive bitrate (ABR) streaming adjusting to low-bandwidth mobile connections.
- Build interactive classroom features: live whiteboard synchronization, chat, and breakout rooms.
- Monitor real-time packet loss, jitter, and frame rate metrics across global regions.

## Required Qualifications
- 4+ years in video streaming or real-time communications.
- Deep understanding of WebRTC protocols, ICE, STUN/TURN, and RTP/RTCP.
- Proficiency in Go, C++, or Node.js.
- Experience with scalable media server deployments.
