# Applied Cryptography & PKI Engineer
**Company**: CryptoShield Core
**Department**: Cryptographic Security
**Location**: Multiple Locations / Remote

## Role Overview
Implement cryptographic key lifecycle management, TLS certificate authorities, and data-at-rest encryption.

## Key Responsibilities
- Manage enterprise Public Key Infrastructure (PKI) and certificate automation with HashiCorp Vault.
- Advise software engineering teams on secure implementation of symmetric/asymmetric encryption algorithms.
- Conduct architectural planning for Post-Quantum Cryptography (PQC) algorithm migrations.
- Audit cryptographic libraries and random number generation implementations.

## Required Qualifications
- 4+ years in applied cryptography, PKI, or security engineering.
- Strong mathematical foundation in number theory and modern cryptography (AES, RSA, ECC).
- Hands-on experience with HashiCorp Vault, AWS KMS, or HSM hardware.
- Programming proficiency in C, C++, or Go.
