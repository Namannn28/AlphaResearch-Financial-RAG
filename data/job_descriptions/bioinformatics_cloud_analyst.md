# Bioinformatics Cloud & Genomic Data Analyst
**Company**: HelixData Genomics
**Department**: Computational Biology
**Location**: Multiple Locations / Remote

## Role Overview
Analyze large-scale whole-genome sequencing datasets and run automated cloud bioinformatics pipelines.

## Key Responsibilities
- Execute variant calling and RNA-seq expression analysis on AWS Batch using Nextflow.
- Perform statistical association testing (GWAS) on large patient cohort genomic datasets.
- Visualize genomic intervals and gene expression distributions using R (Bioconductor) and Python.
- Curate clinical variant interpretations according to ACMG guidelines.

## Required Qualifications
- MS or PhD in Bioinformatics, Computational Biology, or Human Genetics.
- Strong proficiency in R (Bioconductor) and Python (Pandas, SciPy).
- Familiarity with genomic file formats (VCF, BAM, BED, FASTA).
- Experience with cloud bioinformatics pipelines.
