# GitOps Platform Specialist (ArgoCD / Flux)
**Company**: DeclarativeCloud
**Department**: Platform Delivery
**Location**: Multiple Locations / Remote

## Role Overview
Modernize deployment workflows by enforcing 100% declarative GitOps across enterprise clusters.

## Key Responsibilities
- Manage enterprise ArgoCD or Flux deployments syncing thousands of application manifests.
- Implement progressive delivery (canary, blue-green) with Argo Rollouts and Prometheus metrics analysis.
- Secure GitOps repositories with signed commits and automated pull request validation.
- Troubleshoot out-of-sync cluster states and drift reconciliation.

## Required Qualifications
- 3+ years in cloud-native deployment with dedicated GitOps tools.
- ArgoCD, Argo Rollouts, Flux, Helm, Kustomize.
- Solid Kubernetes administration foundation.
- Understanding of infrastructure-as-code principles.
