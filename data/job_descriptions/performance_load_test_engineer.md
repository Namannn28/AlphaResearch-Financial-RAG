# Senior Performance & Load Testing Engineer (k6 / Locust)
**Company**: StressTest Solutions
**Department**: Reliability Testing
**Location**: Multiple Locations / Remote

## Role Overview
Design realistic load tests, stress tests, and spike tests uncovering system bottlenecks before major sales events.

## Key Responsibilities
- Script complex realistic user simulation scenarios using k6, Locust, or Gatling.
- Execute stress tests scaling to 100,000 concurrent virtual users against staging clusters.
- Analyze database connection pool exhaustion, CPU saturation, and memory limits during load.
- Author executive capacity planning reports with recommendations on autoscaling thresholds.

## Required Qualifications
- 4+ years dedicated performance and load testing.
- Proficiency in JavaScript (for k6) or Python (for Locust).
- Deep understanding of HTTP performance, connection reuse, and network latency.
- Experience analyzing distributed trace bottlenecks in Datadog or Grafana.
