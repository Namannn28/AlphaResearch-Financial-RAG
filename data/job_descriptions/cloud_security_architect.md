# Lead Cloud Security Architect (AWS / GCP)
**Company**: ShieldCloud Security
**Department**: Information Security
**Location**: Multiple Locations / Remote

## Role Overview
Architect cloud security postures, IAM least privilege policies, and automated threat detection.

## Key Responsibilities
- Design AWS IAM least-privilege permission boundaries and SCP guardrails.
- Deploy automated cloud security posture management (CSPM) using AWS Security Hub and Wiz.
- Automate threat detection and incident response workflows with AWS GuardDuty and Lambda.
- Conduct cloud architecture security reviews for newly planned enterprise workloads.

## Required Qualifications
- 6+ years in cloud security architecture.
- AWS Certified Security – Specialty or CISSP.
- Hands-on experience with CSPM tools (Wiz, Orca, Prisma Cloud).
- Deep knowledge of IAM policies and cryptographic KMS key management.
