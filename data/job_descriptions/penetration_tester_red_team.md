# Senior Penetration Tester & Red Teamer
**Company**: CyberBreach Labs
**Department**: Offensive Security
**Location**: Multiple Locations / Remote

## Role Overview
Conduct black-box penetration tests, red-team adversary simulations, and exploit research.

## Key Responsibilities
- Perform external and internal penetration tests across cloud networks and public APIs.
- Simulate real-world adversary tactics based on the MITRE ATT&CK framework.
- Author comprehensive technical vulnerability assessment reports with remediation guidance.
- Develop custom exploitation scripts in Python and Go.

## Required Qualifications
- 4+ years in offensive security and ethical hacking.
- Offensive Security Certified Professional (OSCP) or OSCE.
- Proficiency with Burp Suite Pro, Metasploit, Nmap, and Cobalt Strike.
- Deep understanding of web vulnerabilities and privilege escalation.
