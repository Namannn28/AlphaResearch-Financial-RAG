# Identity & Access Management (IAM) Specialist
**Company**: IdentityLock Corp
**Department**: Identity Security
**Location**: Multiple Locations / Remote

## Role Overview
Design centralized identity management, Single Sign-On (SSO), and lifecycle access policies.

## Key Responsibilities
- Architect enterprise SSO, MFA, and user provisioning using Okta, Azure AD, and SCIM protocol.
- Implement fine-grained Role-Based Access Control (RBAC) and Attribute-Based Access Control (ABAC).
- Automate privileged access management (PAM) and credential rotation with CyberArk.
- Conduct quarterly user access reviews and audit access certifications for compliance.

## Required Qualifications
- 4+ years in IAM and identity security.
- Deep understanding of OAuth 2.0, OpenID Connect (OIDC), and SAML 2.0.
- Experience with Okta, Azure AD, or Ping Identity.
- Python scripting for automated identity reconciliation.
