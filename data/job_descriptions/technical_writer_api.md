# Senior Technical Writer & Documentation Specialist
**Company**: DocCraft Systems
**Department**: Developer Experience
**Location**: Multiple Locations / Remote

## Role Overview
Create world-class developer documentation, API reference guides, and interactive code walkthroughs.

## Key Responsibilities
- Author comprehensive developer quickstart guides, API references, and architecture overviews.
- Maintain documentation-as-code workflows using Markdown, MDX, and Git version control.
- Test all code samples and API curl requests to guarantee 100% accuracy.
- Collaborate with product and engineering teams to document newly shipped features ahead of releases.

## Required Qualifications
- 3+ years technical writing for developer-focused software products.
- Familiarity with OpenAPI/Swagger specifications and docs-as-code tools (Docusaurus, Mintlify).
- Basic coding ability in Python or JavaScript to verify sample code.
- Meticulous eye for grammar, clarity, and developer usability.
