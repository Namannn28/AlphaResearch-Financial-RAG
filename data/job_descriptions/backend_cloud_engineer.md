# Senior Backend & Cloud Engineer
**Company**: Horizon Intelligence
**Location**: Austin, TX / Remote
**Department**: Core Product Engineering

## Role Overview
We are looking for a Senior Backend & Cloud Engineer to develop robust APIs, microservices, and distributed backend services powering our platform. You will build high-concurrency event-driven services, optimize relational and NoSQL databases, and partner with frontend engineers to deliver performant web applications.

## Key Responsibilities
- Design, implement, and maintain scalable APIs using TypeScript/Node.js, Go, or Python.
- Architect low-latency database schemas and optimize query execution plans on PostgreSQL and Redis.
- Champion cloud infrastructure automation and deployment workflows with Docker, Kubernetes, and AWS.
- Implement security best practices, OAuth2/OIDC authentication, and fine-grained authorization.
- Write clean, maintainable code with thorough unit, integration, and load testing.

## Required Qualifications
- 4+ years of professional backend software engineering experience in modern production environments.
- High proficiency in TypeScript/Node.js, Go, or Python.
- Proven experience with relational databases (PostgreSQL query tuning, indexing, migrations).
- Hands-on experience with containerization (Docker), CI/CD pipelines, and cloud platforms (AWS/GCP).
- Deep familiarity with API architectural patterns (REST, GraphQL, gRPC) and caching strategies.

## Preferred Qualifications
- Experience leading frontend-to-backend API contract design with GraphQL federation.
- Experience with Site Reliability Engineering (SRE) principles and distributed tracing.
