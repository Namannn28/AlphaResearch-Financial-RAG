# Principal Big Data Architect (Databricks / Spark)
**Company**: OmniScale Data
**Department**: Enterprise Data
**Location**: Multiple Locations / Remote

## Role Overview
Design petabyte-scale analytical data platforms and govern architectural standards across multiple data teams.

## Key Responsibilities
- Architect enterprise Databricks lakehouse platforms on AWS utilizing Unity Catalog.
- Optimize Spark query physical execution plans, broadcast joins, and shuffle partitions.
- Establish enterprise data governance, lineage tracking, and compliance frameworks.
- Evaluate emerging storage formats (Iceberg vs Delta vs Hudi) and provide architectural roadmaps.

## Required Qualifications
- 8+ years data engineering with 3+ years in principal or architecture roles.
- Deep mastery of the Apache Spark engine internals and memory tuning.
- Hands-on experience with Databricks Unity Catalog and cloud infrastructure (Terraform).
- Executive communication skills.
