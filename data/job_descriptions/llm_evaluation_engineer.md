# LLM Evaluation & Benchmarking Engineer
**Company**: TrustAI Corp
**Department**: Model Reliability
**Location**: Multiple Locations / Remote

## Role Overview
Develop rigorous automated evaluation harnesses to benchmark LLM accuracy, safety, and retrieval precision.

## Key Responsibilities
- Build programmatic evaluation suites measuring Ragas metrics (Context Precision, Faithfulness, Answer Relevance).
- Curate high-quality ground-truth evaluation datasets with human and LLM-as-a-judge pipelines.
- Automate adversarial red-teaming tests for prompt injection and jailbreaks.
- Generate standardized model cards and benchmark telemetry reports.

## Required Qualifications
- 3+ years in NLP/ML evaluation or data science.
- Experience with evaluation frameworks (Ragas, TruLens, DeepEval).
- Strong Python programming and statistical testing skills.
- Familiarity with prompt engineering and LLM failure modes.
