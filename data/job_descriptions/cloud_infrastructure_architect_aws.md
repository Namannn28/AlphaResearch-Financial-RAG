# Principal Cloud Solutions Architect (AWS)
**Company**: CloudScale Consulting
**Department**: Cloud Architecture
**Location**: Multiple Locations / Remote

## Role Overview
Design secure, multi-account, highly available cloud foundations for enterprise migrations.

## Key Responsibilities
- Design multi-account AWS Organizations landing zones with Control Tower and IAM Identity Center.
- Architect cross-region disaster recovery and VPC transit gateway network topologies.
- Ensure compliance with AWS Well-Architected Framework across security, reliability, and cost.
- Advise CTOs and VP of Engineering on cloud migration strategies.

## Required Qualifications
- 8+ years cloud infrastructure experience with AWS.
- AWS Certified Solutions Architect – Professional.
- Deep expertise in Terraform, AWS Organizations, and networking.
- Executive client advisory experience.
