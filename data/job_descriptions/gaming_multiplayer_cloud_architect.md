# Gaming Cloud Infrastructure Architect
**Company**: EpicPlay Studios
**Department**: Game Operations
**Location**: Multiple Locations / Remote

## Role Overview
Architect cloud infrastructure autoscaling dedicated game servers globally to match player concurrency spikes.

## Key Responsibilities
- Build multi-region game server autoscaling infrastructure using Agones and Google Kubernetes Engine (GKE).
- Implement automated DDoS protection and UDP traffic proxying using AWS Shield and Cloudflare Magic Transit.
- Deploy global Redis caching clusters for player inventory and cross-platform friend lists.
- Conduct stress testing ahead of major game season launches.

## Required Qualifications
- 5+ years cloud infrastructure experience with dedicated focus on gaming or real-time workloads.
- Kubernetes, Agones, Terraform, AWS or GCP.
- Deep understanding of UDP networking, latency jitter, and DDoS mitigation.
- Passion for online gaming.
