# Machine Learning Data Pipeline Engineer
**Company**: DataNexus AI
**Department**: Data Operations
**Location**: Multiple Locations / Remote

## Role Overview
Build scalable data ingestion, synthetic generation, and multimodal annotation pipelines for AI training.

## Key Responsibilities
- Design petabyte-scale data preprocessing pipelines using Apache Spark and Ray Data.
- Implement automated image/video quality filtering and deduplication using perceptual hashing.
- Manage human-in-the-loop data labeling pipelines with Label Studio.
- Track training dataset lineage and versioning with DVC.

## Required Qualifications
- 3+ years in data engineering for machine learning.
- Apache Spark, Ray Data, Python.
- Experience with dataset versioning tools (DVC, LakeFS).
- Understanding of multimodal data formats (Parquet, WebDataset, TFRecord).
